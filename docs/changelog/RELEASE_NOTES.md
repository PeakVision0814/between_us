# 版本更新日志

## Unreleased

### 认证与注册更新

- 登录页升级为双模式：支持邮箱 / 手机号 + 密码登录，也支持邮箱 / 手机号 + 验证码登录
- 注册链路改为“先验证验证码，再在注册页内一次性完成密码、昵称、性别”
- 新增 `profiles.has_password` 作为账号状态字段，用于区分“注册未收尾完成”和“历史资料缺口待补全”
- `BetweenUsApp` 根据 `has_password`、昵称、性别决定进入注册收尾页、历史资料补全页或主界面
- 生日不再作为注册完成条件，改为后续个人资料补全 / 编辑字段

### 账号与安全

- 账号与安全页新增密码状态展示，支持未设密码账号补设密码，已设密码账号修改密码
- 邮箱 / 手机号 / 密码状态与辅助邮箱状态统一收口到个人资料下的“账号与安全”入口
- 注册收尾完成或后续设置密码时，都会把 `profiles.has_password` 持久化为 `true`

## 0.1.0 (2026-06-05)

### 版本概述

这是 Between Us 的第一个正式版本，完成了核心功能的基础搭建，包括用户认证、双人空间、日历、计划、随记、多语言支持、纪念日功能等。

### 新增功能

#### 用户认证与资料
- 认证基础链路（登录 / 注册分离）
- 登录与注册分离
- 个人资料设置（昵称、性别、生日）
- 个人资料编辑与展示

#### 双人空间
- 邀请码生成与输入
- 双人空间配对
- 空间状态展示
- 退出空间机制（MVP）
- 单人态/双人态能力边界

#### 日历功能
- 月视图日历
- 创建约会/提醒事件
- 事件软删除（带确认弹窗）
- 选中日期详情展示
- 近期事项列表
- 作者昵称显示

#### 计划笔记
- 计划创建与展示
- 随记创建与展示
- 计划/随记模式切换
- 作者昵称显示

#### 首页
- Hero Card（情侣关系故事卡）
- 情绪价值文案随机轮换
- 在一起天数展示
- 伴侣头像与昵称
- 下拉刷新

#### 我们页
- 关系 Hero 展示
- 伴侣资料展示
- 邀请入口（单人态）
- 空间状态入口（双人态）
- 纪念日设置（相识纪念日、恋爱纪念日、自定义纪念日）

#### 纪念日功能
- 新建 `anniversaries` 表
- 预置固有纪念日（相识纪念日、恋爱纪念日）
- 自定义纪念日（最多两个）
- 首页纪念日倒计时展示
- 纪念日日期修改
- 纪念日删除

#### 多语言支持
- 支持 5 种语言：简体中文、繁體中文、English、日本語、한국어
- 集中式语言配置（AppLanguage）
- 核心路径文案全覆盖

#### 其他功能
- Realtime 数据同步（Supabase Realtime）
- 手动刷新（下拉刷新）
- 软删除机制（日历事件、计划、随记）
- 作者昵称显示

### 技术栈

- **前端**：Flutter 3.x
- **后端**：Supabase（PostgreSQL + Auth + Realtime）
- **状态管理**：ChangeNotifier + InheritedNotifier
- **多语言**：手写 AppStrings 类
- **测试**：flutter_test

### 数据库表结构

- `profiles` — 用户资料
- `couple_spaces` — 双人空间
- `couple_memberships` — 空间成员关系
- `couple_invites` — 邀请码
- `calendar_events` — 日历事件
- `plans` — 计划
- `notes` — 随记
- `anniversaries` — 纪念日

### 版本号规范

采用语义化版本（Semantic Versioning）：
- **主版本号（Major）**：重大功能变化或不兼容更新
- **次版本号（Minor）**：新功能添加，向后兼容
- **修订号（Patch）**：Bug 修复，向后兼容
